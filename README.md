# Kurrent ♞

Kurrent ♞ is a Telegram-based digital wallet and top-up ecosystem.

## Overview
- Platform: Telegram Mini App
- Currency: ♞
- Conversion: 1 ♞ = 2 Birr 
- Launched: 2025

## What Kurrent Does
Kurrent allows users to deposit balance and spend it on:
- Game top-ups
- Subscriptions
- Digital services

## Trust
Kurrent is privately operated and distributed through Telegram.
